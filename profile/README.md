# Kior Labs

Independent studio building developer tools and agent skills for teams shipping AI systems.

## Products

**[Tracegrade](https://github.com/kior-labs/tracegrade)** — turns production agent traces into a calibrated eval suite: failure clusters, ready assertions, and a judge checked against humans. Runs locally, no model calls.

```bash
npx github:kior-labs/tracegrade --help
```

**[instagram-mcp-plugin](https://github.com/kior-labs/instagram-mcp-plugin)** — an MCP server for Instagram professional accounts: insights, comments, publishing and DMs from inside your agent.
